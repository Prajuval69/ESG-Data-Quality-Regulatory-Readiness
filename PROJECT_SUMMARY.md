# Project Summary

**Business problem:** ESG reporting depends on source data that is complete, valid, consistent, and traceable.

**Approach:** synthetic source data → controlled metric reference → deterministic pandas validation → exception queue → company-year quality scoring → readiness screening → packaged Tableau dashboards.

**Validated results:** 223 source records, 188 records with no automated exception, 37 exception instances, an 84.3% record pass rate, and an 88.4% portfolio-defined weighted quality score.

**BI deliverable:** four Tableau dashboards covering executive health, detailed data quality, regulatory readiness, and exception remediation.

**Limitations:** synthetic data, simplified portfolio rules, no legal determination, and no timeliness/aging metric because source dates are unavailable.
